# FoodExpress - Online Food Delivery UI

Modern responsive UI for a food delivery system built with HTML, CSS, Bootstrap 5, and JavaScript.

## Theme
Orange (#FF6B00) and White clean modern design.

## Pages Included
- index.html - Landing page
- login.html / register.html - Authentication
- home.html - Customer home after login
- restaurants.html - Restaurant listing with filters
- menu.html - Food menu with add-to-cart
- cart.html - Shopping cart (localStorage)
- checkout.html - Checkout & payment selection
- order_tracking.html - Live order tracking
- profile.html - User profile & addresses
- restaurant_dashboard.html - Restaurant partner panel
- delivery_dashboard.html - Delivery partner panel

## Features
- Fully responsive (mobile-first)
- Cart persistence via localStorage
- Interactive quantity controls & toasts
- Simulated login/register flow
- Order status updates on dashboards
- Clean orange-and-white theme

## How to Run
Simply open `index.html` in a browser. All assets are relative.

## Tech Stack
- HTML5
- CSS3 + Bootstrap 5.3
- Bootstrap Icons
- Vanilla JavaScript
- Google Fonts (Poppins)
